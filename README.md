# Beauty Anna LS

Site institucional desenvolvido para apresentar os procedimentos estéticos da Beauty Anna LS.

O projeto foi construído utilizando apenas HTML5 e CSS3, com foco em:

* organização visual
* responsividade
* layout moderno
* mobile first
* boas práticas de estruturação

---

# Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* Grid Layout
* Font Awesome

---

# Funcionalidades

* Header fixo (`sticky`)
* Catálogo de procedimentos
* Cards responsivos
* Efeitos hover
* Botão de contato
* Navegação rápida
* Layout mobile first

---

# Procedimentos disponíveis

* Epilação de buço
* Design de sobrancelhas simples
* Design com henna
* Design com tintura
* Brow lamination
* Lash lifting
* Massagem relaxante
* Limpeza de pele
* Maquiagem
